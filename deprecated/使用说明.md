# 使用说明（Gemini 生图，免 API key）

用你自己的 **Gemini Pro 账号** 批量生成富文本图片（合同、海报、票据等），
**不需要 API key、不走按量计费**。原理和 codex-imgbatch 完全一样——
不申请 API，直接复用 Gemini CLI 的 OAuth 登录，走订阅额度。

---

## 一、和 codex 版的对应关系

| codex 版（你已有的） | Gemini 版（本工具） |
|---|---|
| `codex exec --enable image_generation` | `gemini --yolo -m <图像模型> -p "..."` |
| ChatGPT Plus 订阅额度 | Gemini Pro 订阅额度 |
| `run_my_prompts.py` / `run.bat` | `run_gemini_prompts.py` / `run_gemini_prompts.bat` |
| prompt 文件 CSV/TXT/JSONL | 完全相同，可直接复用 |
| `output/_progress/xxx.progress.json` 续跑 | 完全相同 |

**你现有的 `document_prompts_unified.csv` 可以直接拿来用，不用改任何格式。**

---

## 二、第一次使用（一次性）

### 1. 装 Gemini CLI

```
npm install -g @google/gemini-cli
```

装完在命令行执行 `gemini --version`，能打印版本号就 OK。

### 2. 登录 Google 账号（关键，只做一次）

```
gemini
```

会弹浏览器，选 **Sign in with Google**，登录你的 Gemini Pro 账号即可。
登录状态存在 `~/.gemini/`，之后运行本工具都不用再登。

> 本工具出图前会自动检测登录状态；没登录会直接拦截并提示你这一步。

## 三、每次出图

### 方式一：双击 `run_gemini_prompts.bat`

把 prompt 文件拖到窗口里（或输入路径），之后 Python 会依次问你「生成几张」、
「是否新建文件夹」，和 codex 版手感一致。

### 方式二：命令行

```bash
python run_gemini_prompts.py --input 我的prompt.csv --n 50
python run_gemini_prompts.py --input 我的prompt.csv --fast --n 50     # 用 Flash 模型（快）
python run_gemini_prompts.py --input 我的prompt.csv --check           # 只体检
python run_gemini_prompts.py --input 我的prompt.csv --dry-run --n 5   # 只预览
python run_gemini_prompts.py --input 我的prompt.csv --reset           # 从头重跑
```

常用参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `--n` | 本次生成几张 | 交互询问 |
| `--model` | 图像模型，逗号分隔为回退链 | `gemini-3-pro-image-preview,gemini-2.5-flash-image` |
| `--fast` | 用 Flash 模型（快，文字略差） | 关 |
| `--concurrency` | 并发数 | 2 |
| `--timeout` | 单张超时（秒） | 600 |
| `--retries` | 失败重试次数 | 2 |
| `--proxy` | HTTP 代理，如 `http://127.0.0.1:7890` | 继承终端代理 |
| `--default-aspect` | TXT 缺省比例 | 1:1 |

## 四、模型怎么选（2026 年 GA，来自 Google 官方文档）

| 模型 ID | 昵称 | 特点 | 适用 |
|---|---|---|---|
| `gemini-3-pro-image` | Nano Banana Pro | 非 Flash，质量最高、文字渲染最好、4K | 合同/票据等**富文本**（推荐） |
| `gemini-nano-banana-2.1` | Nano Banana 2.1 | 最新主力，Flash 级速度 + 更好文字 | 大批量主力 |
| `gemini-3.1-flash-image` | Nano Banana 2 | 上一代主力 | 备用 |
| `gemini-3.1-flash-lite-image` | Nano Banana 2 Lite | 最快最便宜 | 快速试跑 |

默认链是「先 Pro、失败自动回退 Nano Banana 2.1」，不用你手动干预；
`--fast` 则切到「Nano Banana 2.1 → Nano Banana 2」。

⚠️ 注意：`Nano Banana 2` 这一路其实是 **Flash 模型**（`gemini-3.1-flash-image`），
真正的「非 Flash 高配」是 `Nano Banana Pro`（`gemini-3-pro-image`）。
带 `-preview` 后缀的旧名字（如 `gemini-3-pro-image-preview`）已停用，勿再用。

## 五、代理（在国内使用必须看）

Google 服务需要科学上网。gemini CLI 会继承你终端里的代理设置；
如果你的代理工具（Clash / V2Ray 等）端口不是自动的，就显式指定：

```bash
python run_gemini_prompts.py --input x.csv --n 10 --proxy http://127.0.0.1:7890
```

`--proxy none` 表示强制直连。

---

## 六、额度说明

Gemini Pro 订阅对图像生成有每日限额（具体数值 Google 会调整）。
本工具**不会**像 codex 版那样内置「周额度 85% 停机」护栏（因为 Gemini
CLI 拿不到确切的额度百分比）。建议：

- 第一次先 `--n 2` 试跑，确认能出图、速度、效果
- 大批量时用 `--concurrency 2`（默认）稳妥；被限流了就调低或加 `--retries`

## 七、产物

出图后，输出目录（默认 `gemini-imgbatch/output/<文件>_out/`）里有：

| 文件 | 说明 |
|---|---|
| `<id>.png` | 成品图，按 sample_id 命名 |
| `_work/<id>/` | 每张图的工作目录（gemini 会话缓存，可删） |
| `../_progress/<文件>.progress.json` | 续跑进度 |

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 提示「尚未登录」被拦截 | 执行 `gemini` 完成 Google 登录，再重跑 |
| 报 `Error auth` / 认证失败 | 见下方「认证失败的排查」 |
| 卡住不动 | 没登录或没代理。检查代理，或用 `--check` 体检 |
| 报「模型不存在」 | 用 `--model` 换一个模型名 |
| 图出来了但文字有错字 | 正常现象，图像模型不保证 100% 字对 |
| 想要不同长宽比 | prompt 文件的 `aspect_ratio` 列（或 `--default-aspect`） |

### 认证失败的排查（Error auth）

1. **看完整报错**：每张失败后，完整日志写在 `_work/<id>/gemini.log`，打开看
   `--- stderr ---` 段落里的具体原因。
2. **确认账号类型**：`--check` 会显示登录的邮箱。如果是 `.onworkspace.com`、
   或带 `@公司域名` 的**企业/Workspace 账号**，Gemini CLI 走 OAuth 时往往
   需要额外设 `GOOGLE_CLOUD_PROJECT`，或这类临时账号根本没有 Gemini Pro
   生图额度。
   - 有 GCP 项目 → 加 `--project 你的项目ID` 再试。
   - 没有 → 换一个真正的个人 Gmail（有 Google AI Pro/Ultra 订阅）重新 `gemini` 登录。
3. **确认账号真能生图**：先在浏览器打开 gemini.google.com，用同一个账号试试
   能不能生成图片。浏览器里都不能生图，CLI 也一定不行。

**报问题时请附上** 终端里的报错信息、`--check` 的体检输出，以及失败那条的
`gemini.log` 内容。
